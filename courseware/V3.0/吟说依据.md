# 山海行歌 V2.0 · 吟说修订依据

2026-10-30

屏幕以诗句和短字幕领路，声音在相应动作中补充释意。新增释读为本课原创教学解说，不冒充李白诗句。入境旁白交代情境，点击后的吟声才展开对应动作与诗意。

两首独立作品的部分诗句由本课重新编排为对读行程。它不是两首原诗的合并全文，也不是李白一次真实行旅的复原。完整原诗与各自出处仍在“两首原诗”中。四顾的廊、檐、城、庭和开门、尝食、叩门等画面属于情境表现。

- 《行路难·其一》的金樽、珍羞、冰雪阻路、姜尚与伊尹典故、“会有时”、云帆、济海等，参照[国家中小学智慧教育平台所载九年级上册语文教材，第 59 页](https://v3.ykt.cbern.com.cn/65/document/69ec38b3e3da416ab984ffd76cdec58e/pdf.pdf)。典故以“相传”引入，不把梦境当作实录。
- 《蜀道难》的文本与字词参照[原诗及注释](https://www.gushiwen.cn/mingju/juv_9ea443b3f9ce.aspx)。参、井为星宿；“膺”为胸，“坐”在此按“徒然”解释。因此英文改为 “I can only sigh”，同步修订字幕、研习解说和英文全文录音。
- 五丁开山与六龙日车明确作为神话、传说讲述。星辰可扪、百步九折、一夫对万夫等，从诗歌的夸张、对照与身体感受来释读，不将其当作地理测量或历史实录。
- 子规指杜鹃；实际声音素材为四声杜鹃录音，署名与许可见“素材署名.md”。以鸟鸣衬幽静、瀑声显险峻，属于依据诗中字词和结构展开的教学阐释。

英文为本课教学译读。新旁白采用“诗句较舒缓、释意稍流动”的两种语速，句间保留呼吸；音乐在人声下渐弱、在句后渐回。动作分段依据本地音频时长安排，同时等待真实播放结束事件，避免转场截断句子。
