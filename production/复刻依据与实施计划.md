# 《蜀道难》互动课件：复刻依据与实施计划

目标：将用户指定视频的电影感诗歌体验、操作布局和学习功能迁移到《蜀道难》，交付独立、可双击运行的完整课件。用户已指定视频为复刻依据；不改变当前教师平台。

## 参考分析

视频 1248×734，30 fps，103.67 秒。全片解码场景差异扫描，保留每秒画面与关键切换原始帧；对控件、动作和布局采用重点帧逐张核查。不是把视频或截图当作可交互课件。

| 参考时间 | 视频内容 | 本课件对应 |
|---|---|---|
| 0–5 s | 大标题、成为诗中之我 | 蜀道难，进入蜀道，初闻咏叹 |
| 6–10 s | 门扉打开与场景推进 | 进入蜀山，追溯蚕丛鱼凫与五丁开山 |

| 21–29 s | 冰川/雪山受阻、动态粒子 | 青泥盘旋、扪参历井、抚膺长叹 |

| 42–49 s | 可拖拽环视的意象空间 | 高山/栈道/剑阁三维结构示意，旋转、缩放、雾气 |

| 69–79 s | 配乐/旁白独立音量、全文朗读 | 分段朗读、全诗朗读、独立音量、暂停/重听/静音 |
| 80–91 s | 课堂解读、章节跳转与暂停 | 当前章侧栏精读、直接跳转、暂停、键盘控制 |
| 92–101 s | 终章回望与再读 | 三叹回望、完整原文、重走蜀道 |

## 视觉约定

只复刻视频内课件，录屏外的宣传标题和时间条不属于课件。铺满浏览器视口；顶栏品牌左、教学工具右；左侧大诗句；中下方旁白；右下金色细框主按钮；底部章节导航。色彩为墨青 #06151c、深海青 #10262d、青灰 #8b9a98、古金 #d8bd83、暖白 #f2eee0。展示字体使用本机楷体/宋体，工具字体为微软雅黑；不依赖在线字体。

背景为专门生成的山川意境图；栈道、星宿热点、雨雾、镜头变化为独立可交互图层。场景与三维意象属于教学艺术示意，非真实地形复原。主场景和弹窗均按状态分页，无长篇滚动。

- [x] 实测：真实浏览器 file://，完整流程与分支，声音控制，多尺寸截图，键盘操作与错误检查。
- [x] 交付：根目录含 index.html 的 ZIP，实际解压复验；记录与截图留包外。

技术：HTML/CSS/原生 JavaScript，本地静态资源，无构建或服务器要求，无账户与外部服务。各模块以公共状态串联，退出时停止音频/动画，暂停阻止场景推进。资料和图片来源随包说明。
