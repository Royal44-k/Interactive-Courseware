# V3.0 动效与导航修订验收

本次仍为 V3.0。已更新工作目录、4180 预览和离线压缩包。修订前压缩包保存在本目录“山海行歌-V3.0-修订前.zip”；V1.0 与 V2.0 未改动。

## 四项修订

1. **首页云海**：原实现仅有细微局部形变，视觉反馈不足。本次改为多尺度云团卷舒、随时间演变的密度与光照，以及缓慢随机变风。局部云区运动，山体保持固定。按正常时钟录制 8 秒片段“首页云海实录.mp4”，并保留四帧原始云层图。样本前后约 7.5 秒：云区平均像素差 19.14，固定岩体取样区为 0。数值只作为变化证据，另已检查完整画面。
2. **飞湍湿屏**：水珠先在镜面挂留，达到滑移条件后拉长成窄颈水流；后方留下持续的透明折射水膜、弯曲边缘和逐渐退去的水痕。折射采样对齐实际镜头位置，避免错位形成深色细划痕。下滑前端宽高比约 0.34，不使用圆形下落；支持暂停、擦拭和跨幕渐隐。
3. **前进箭头**：底部右侧补齐“下一幕”，与左侧“上一幕”相对应，可直接导航。首页左箭头停用，终章右箭头停用；原来的动作按钮和必修研读、考核流程保持。
4. **进度轨道**：起点对应“序·入境”，共七个圆形节点，首页即亮。节点与文字处于同一轨道，色调承接各章节。删除旧进度元素、章节活动横条及访问装饰；单一流体色带不再叠加内层细线或底栏边线。内置预览的 807 像素宽度下七节点全部可见，窄手机屏使用同轨横向滑动。

浏览器刷新曾出现新 HTML 与缓存旧脚本混用；现在所有本地 JS/CSS 都带本轮资源版本标记。当前预览为 <http://127.0.0.1:4180/?v=V3.0-motion-r4>。
