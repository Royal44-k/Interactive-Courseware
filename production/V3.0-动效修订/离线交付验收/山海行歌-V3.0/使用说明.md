# 山海行歌 V3.0

李白《行路难·其一》×《蜀道难》 · 中英双语诗境

李太白邀君同游，诗吟蜀道之险峻，歌咏云海之壮丽。

完整解压后，用 Edge 或 Chrome 打开 index.html。画面、吟声、配乐与环境声均保存在本地，可离线使用。首次打开请等“走入山海”按钮亮起。建议电脑横屏观看。

## 行游

- **自动吟游**：首页点击后随诗进入 24 幕。入境吟声引出情境，诗句与释意随动作展开，稍作呼吸便续行。途中手动行游也可随时点右上“自动吟游”，从当前一幕接续。
- **走入山海**：手动参与。入境吟声结束后按钮亮起鎏金波纹；点击执行动作，再点击续行。拔剑一幕渐暗后自动进入下一幕。
- **暂歇**：同时暂停画面、动作和声音。自动行游暂停后，点“继续自动吟游”、右上的同名按钮或空格继续，保持原来的行程。
- **转为手动**：保留当前一幕，由自己把握节奏。
- **顶栏全屏**：进入或退出全屏。**中 / 中·EN / EN**：中文、中英对照与英文；中英对照默认中文吟声。切换语言或用地图跳转会退出自动吟游。
- **行游小记 → 调弦听音**：独立选择吟声语言、调整音量、开关配乐或静音。
- **两首原诗 / 双诗研习 / 字句赏析**：阅读原文、译读、字词与解说；部分内容可点播。
- **空格或 →**：动作、继续或从暂停恢复；**←**：上一幕；**P**：暂停 / 继续；**Esc**：关闭面板。

打开研习面板时，当前动作与吟声暂停；关闭后接续。面板中更换吟声语言后，会以新语言重入当前一幕；原先已暂停则保持暂停。页面转入后台也会暂停，回来后可继续。

## 本版画面与互动

首页的山体与树木保持固定，只让云雾区域流动、卷舒、消散，风向与扰动逐渐变化；本轮增强了多层云团的卷舒及明暗变化，并保持山体固定。月下子规的喙与呼吸动作随真实鸟鸣起落；流水飞湍会溅到镜面，水珠先挂留、继而拉长成细流，留下透明折射水膜和逐渐消退的痕迹，可点击“拂去水珠”或按住鼠标拂过画面。离开该幕后水迹渐退。垂钓时鱼线保持稳定，水纹仍流动。

底部略加粗的流体进度带配有七个节点：序·入境与六个章节。首页即点亮起点，抵达后按章节色调亮起并保持微光；节点与章节文字同轨，窄屏可横向滑动。底部左、右箭头分别直达上一幕与下一幕。终章右箭头停用，请按主要按钮进入研习。系统启用“减少动态”时，云海与装饰动画停息，仍可完成吟游和考核。

沿用 V2.0 的完整中英吟说与补充释读，保留 24 幕和分段音画同步。终章改为研读与考核引导，并配有新的中英文录音。按钮上方不显示动作进度条。

## 行后研读与必修考核

终章进入“山海已过，字句待深”。依次回看原诗、研习、字句赏析、行游小记，在各页末尾点“已读此页”，开启“百川归卷”。

考核总分 100，含选择、填空、连线、新作情景拼图、两道赏析问答和心得体会。客观题共 60 分，由系统计分；表达题共 40 分，按明确量规自评并单独标注，供教师复核，不是教师核定成绩。

题目可前后切换，草稿自动保存在当前浏览器。全部作答并选完量规后方可提交；提交后显示答案依据、分项成绩与表达记录，可“保存学习记录”并“带着诗意，回到首页”。学习记录为 JSON 文件，包含完整答案与评分量规。更换浏览器、清除浏览数据或移动离线目录可能影响草稿恢复。题目依据、分值和评分边界见“考核说明与依据.md”。

## 文本与素材

两诗保留各自出处与结尾情绪，衔接是教学编排，并非李白一次真实旅行的复原。英文为教学译读；图像为诗意化创作，不作为唐代器物、建筑或地理的考证图像。释读依据见“吟说依据.md”，素材许可见“素材署名.md”。V1.0、V2.0 均独立保留。

## English guide

Extract the complete folder and open index.html in Edge or Chrome. All media work offline. Choose **Guided journey** on the opening page, or **Begin the journey** for manual exploration. The top-right **Guided journey** control also starts automation from the current scene. **Pause** freezes image, gesture and sound; **Resume guided journey** continues from the same point. **Take control** switches to manual exploration.

The full-screen control is in the top bar. **EN** selects English; **中 / EN** selects paired reading. **Guide → Sound settings** chooses the voice independently. Language changes and map navigation return to manual control. **Space / →** acts or resumes; **P** pauses; **Esc** closes a panel.

At the end, revisit the poems, study notes, verse exploration and guide. Mark each page as read to unlock the required 100-point assessment. Objective tasks account for 60 points; close reading and reflection account for 40 explicitly self-assessed points, for teacher review. The puzzle uses a new image. Drafts stay in this browser. Submit all tasks to see your learning record, export it as JSON and return to the opening.

This is an imagined paired reading, not a reconstruction of Li Bai’s historical travels. See “素材署名.md” for media credits and “考核说明与依据.md” for assessment sources and scoring.
