# 百川归卷 · 考核说明与依据

本考核将《行路难·其一》与《蜀道难》并读，由字词、诗句和典故，逐步进入意象比较、赏析与个人表达。公开导学材料用于参考考点，题干、选项、反馈与量规均重新编写。

| 环节 | 内容 | 分值 | 计分方式 |
| --- | --- | ---: | --- |
| 辨字 | 4 道选择 | 20 | 自动判定 |
| 补句 | 4 道原句填空 | 16 | 忽略标点与空白，兼容题内常用繁体字 |
| 连意 | 4 组典故、词句与释意连线 | 12 | 每组 3 分 |

| 赏析 | 声音意象、两诗结尾比较 | 24 | 2 题，各 3 项量规，每项 0 / 2 / 4 分自评 |
| 心得 | 从诗句联系具体经历与下一步行动 | 16 | 4 项量规，每项 0 / 2 / 4 分自评 |
| 合计 | 客观题 60 分 + 表达题 40 分 | **100** | 表达题自评与客观成绩分别标示 |

赏析和心得允许多种有依据的合理表达。系统检查是否完成作答与量规选择，不用关键词或字数替代文学质量判断。结果页明确写明“含表达题自评分”，不将其冒充教师核定成绩。学生可导出包含答案和量规的 JSON 学习记录，交由教师复核。
