# 山海行歌 V3.0 · 交付验收

日期：2026-10-30。独立于 V1.0、V2.0，保留完整中英文 24 幕、V2.0 补充释读与氛围音乐。

## 七项改进

| 请求 | 实现与检查 |
| --- | --- |
| 首页自然云海 | 固定底图，用单独云区遮罩与连续噪声流场改变局部云雾；风向随机缓变。前后帧对照中，选定山体区域像素差为 0，云区有持续变化。不是整图平移。 |
| 动态子规 | 原鸟图分为身体、头、喙、尾等片段，站足固定；喙动作由原真实鸟鸣的频段包络驱动，辅以轻微呼吸、转头和随机眨眼。暂停后音画一同冻结。 |
| 流体进度 | 约 3.7 像素的流动色带、六个圆形章节节点，按金、冰青、青灰、月蓝、竹绿、曙金点亮；桌面节点与章节名称中心对齐。 |
| 飞湍湿屏 | 动作中飞沫击中画面，凝成水珠后滑落并留痕；可点击“拂去水珠”或按住鼠标拂过画面，退出该幕后渐隐。 |
| 自动吟游恢复 | 自动与暂歇并排；手动中可转自动，暂停后可以遮罩按钮、顶部自动按钮或空格恢复。修复暂停遮罩挡住顶部自动按钮的问题。 |
| 垂钓鱼线 | 水流着色器排除鱼竿与鱼线区域，水面继续流动。直接读取原始画布对照，鱼线保护区像素差为 0。 |
| 研读与必修考核 | 终章以新中英文录音引导原诗、研习、赏析、小记；四页确认已读后开启六类 100 分考核。新作拼图不用于行游。完成后显示结果、导出与回首页。 |

## 验证证据

- `checks/auto-zh.json`、`auto-en.json`：中英各走完 24 幕，每条流程 59 段入境与动作吟声，无重复触发、重叠播放或运行错误，终章进入研读。为控制验收时长，完整流程测试在测试脚本中同时以 4 倍时钟推进动画与音频，产品代码不变。
- `checks/motion-report.json`：正常时钟检查子规、湿屏、擦拭、跨幕淡出、暂停冻结、手动转自动与两条自动恢复路径。子规静默与鸣叫时喙幅度有明确区分。
- `checks/pixel-report.json`：首页山体与云区对照；垂钓原始画布稳定区与流水区对照。鱼线不能用经过镜头缩放、被页面裁切的元素截图直接按纹理坐标取样，最终检查使用原始 WebGL 画布。
- `checks/assessment-report.json`：四页研读门槛、未答完拦截、六类作答、连线、拼图、草稿恢复、导出、完成后回首页，以及 100 分与 0 分边界。
- `checks/final-layout-report.json`：12 组封面布局，9 组结果页固定底栏；中文、中英、英文及手机、横屏、桌面尺寸。自动与暂歇并列，保存和回首页均可见。
- `checks/delivery-report.json`：从实际 ZIP 解压目录运行，并使浏览器断网。176 段音频和 54 张 PNG 均加载成功，15 组语言与屏幕尺寸检查、瀑流擦拭和考核拼图检查通过，无运行错误。
- 本机 Edge、1440×900、连续 8 秒首页采样：481 帧，帧间隔 P95 为 17 毫秒，未出现超过 34 毫秒的采样。该结果属于本机测试，不承诺所有设备达到相同帧率。
- 视觉检查覆盖首页桌面与手机、子规、飞湍湿屏、考核选择、连线、拼图与结果页。上述声音检查核验实际播放事件和时长，不冒称人工逐句试听。

## 考核与素材说明

100 分由 60 分自动计分的客观题和 40 分按量规自评的赏析、心得构成。结果明确标示自评分，供教师复核；系统不以关键词或字数假装判断文学表达质量。草稿保存在当前浏览器，不能替代有账号的教师阅卷系统。

联网参考的教材与公开导学材料、题目分值及评分边界见交付目录中的“考核说明与依据.md”，页面也提供来源入口。所有题干、选项和反馈重新编写，不照搬公开题库全文。

新图保存路径、原始生成文件与提示要点见 `image-prompts.json`；视觉约定见 `design-notes.md`。生成场景用于诗意表达，不作为历史地理考证图像。
