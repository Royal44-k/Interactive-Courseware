# V3.0 视觉与交互约定

对象：学习李白双诗的学生。主体仍是满幅山海，阅览与答卷只在行后打开。

色彩：墨蓝 #081e27、纸白 #e9e3d0、旧金 #d6ba7e、冰青 #a7dce7、月蓝 #afbee0、竹绿 #b0d0b4。中文诗题宋体，英文诗意 Georgia；按钮与说明沿用系统清晰字形。进度节点颜色承接六个章节，考核用旧金细边和竖向阅读节奏。

首页的特征是静山与动云的对照。云层蒙版独立保护山体、树、栈道；随机风向平缓变化，不整图平移。子规头、喙、胸、尾分别变形，喙动作由原始鸟鸣的 1000—1300 Hz 包络驱动；滤波只用于分析动作，不替换原始录音。瀑流飞沫先撞镜，再形成停驻水珠与重力滑痕；退出场景逐渐隐去。

行后以四页回看通向六程考核，不使用展示型大数字仪表盘。唯一大数字出现在交卷结果，且明确标出自评分，避免把自动客观题计分与主观评价混为一谈。

新图使用内置 imagegen 生成：
- `assets/v3-cloud-mask.png`：对现有首页进行云层分割，云雾白、山体与天空黑；保留构图。
- `assets/v3-cuckoo-forest.png`：仅去除原画子规，补回其后山林与枝干，保留月色和构图。
- `assets/v3-exam-gorge.png`：新作 3:2 峡谷，左侧坚实石栈、右侧苍松飞瀑、下方回流，用于六块拼图；不在行游场景使用。

原始生成文件保存在 Codex generated_images，项目内保留独立副本。生成提示词见 `image-prompts.json`。
