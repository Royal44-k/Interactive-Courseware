## 46.5–51.25 秒的三维证据

初态是画面中央偏右的斜侧面木帆船；两个桅杆、两面帆、舷边、甲板、船艉可区分。约 47.25–49.5 秒船由斜侧转向迎面视角，船舷可见面积改变，两面帆逐渐互相遮挡，侧向船长压缩为正面的窄宽度；约 49.5–51 秒保持正面。水面亮斑与波纹在船姿态保持期间仍继续变化，远处山体也有空间遮挡。约 51.25 秒退出并叠回主流程。

能够据录屏确认：**模型具有体积和视角相关遮挡；场景含动态水面；界面提示可拖拽环视，并呈现风力滑杆、缩放/重置类控件。** 这段录屏没有逐一演示所有控件，不能把“每个控件均已验证”写成观察结论。新课件应实际验证拖拽、滚轮、重置、参数改变的可见结果。

## 移植《蜀道难》的可验收动作

下列时长是建议的新体验目标，不是对参考视频的额外事实声称。每一项必须保存初态、约 1/3、约 2/3、终态四张连续截图；至少录制一次正常速度全过程。只查 DOM 状态或最后一帧不能证明动作成立。

1. **开山成路（1.5–2.5 秒）**：岩壁/断口遮住通路 → 岩块震动、分离并向下坠落 → 木栈板/梁逐段落定，形成实际可行走的通路。终态能看出新出现的几何实体和深度，不能只画一根发光虚线。
2. **迈步上栈道（每步约 0.6–1 秒）**：近处栏杆和板缝在脚前 → 镜头沿道路前移并轻微上下起伏，近栏杆位移大、远山位移小 → 经过一组栏杆，出现新的转弯/遮挡。连续三步不能只是同一图片累计放大。
3. **仰观/俯察（各约 1 秒）**：眼平高度 → 镜头俯仰带来峰顶或崖下激流的实际视野变化 → 顶部天空/底部深谷新增进入画面，近崖与远山位置关系不同；UI保持固定。
4. **扪参、抚膺（伸手约 0.8 秒，收手/俯身约 1.2 秒）**：写实手臂在屏外 → 手指随臂伸向目标星，接近后星光只在接触处反馈 → 手收回至胸前，镜头轻降、呼吸节奏放缓，停在抚膺终态。保持手指、腕、袖口连接；不能用两个光圈替手。
5. **飞鸟越林（约 1.5–2 秒）**：鸟藏在近树后 → 扑翼由树后进入视野、掠过中景 → 被另一树/岩石遮挡或飞入远处缩小。叫声与进入视野对应，不能只有声音按钮变色。
6. **飞湍转石（连续循环，增强过渡约 1 秒）**：可辨水流方向 → 流速、白沫、雾气和滚石运动共同增强 → 石块在崖壁/溪床发生遮挡与落势。调节“水势”必须改变水自身，不能只增加雨点。
7. **剑阁受阻/回望（约 1.5 秒）**：关口/近崖占据通路 → 门扉转动或关口几何实际收窄，近景遮挡增强 → 留下“一夫当关”的狭窄通道；回望需镜头改向，出现来路的空间关系。可复用参考门扉的左右独立大前景机制。
8. **三维空间**：拖动 90° 后峰、栈道梁、斜撑、关口的相互遮挡改变；至少能够观察正、侧、后不同面。缩放改变距离，重置回到确定构图；雾/水可在停止拖动后继续流动。把山川的体积、悬空栈道与关口狭窄关系放在主舞台。

所有动作的共同底线：按钮触发后，应先看到物体或镜头连续行动，再落在可停留、可重放的物理终态。文字、语音与学习工具围绕这一过程组织。
