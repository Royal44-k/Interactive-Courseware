## 2. 原文核对结论

`poem` 包含完整三段，分段与教材一致：

1. 从“噫吁嚱”至“以手抚膺坐长叹”。
2. 从“问君西游何时还”至“嗟尔远道之人胡为乎来哉”。
3. 从“剑阁峥嵘而崔嵬”至“侧身西望长咨嗟”。

保留教材的“然后天梯石栈相钩连”“黄鹤之飞尚不得过”“畏途巉岩不可攀”“砯崖转石万壑雷”“其险也如此”等写法；不混入其他版本的“方钩连”“其险也若此”等异文。正文全部为公版古诗原文；章节说明、提问和参考回答均另行组织，不照抄现代赏析段落。

六个教学章节是为了交互浏览而作的教学分组，不宣称是原作固有的六段。六章的诗句按原诗顺序衔接，完整覆盖全文；第五章跨越教材第二、三段的界线，以便讨论从自然险阻向人事忧虑的转折。

## 3. 字音、词义与边界

教材明确标注并已复核的易读错处包括：噫吁嚱 yī xū xī，猱 náo，扪 mén，参 shēn，巉 chán，豗 huī，砯 pīng。其他拼音按现代普通话的相应词义标注，例如秦塞的“塞”读 sài，悲鸟号古木的“号”读 háo，参为星宿名不读 cān。

关于“砯崖转石”的“转”：所核教材给出“使滚动”的释义，但未标这个字的拼音。本课件取 zhuǎn。补查并打开[汉典“转”字条](https://zdic.net/hans/%E8%BD%AC)，其 zhuǎn 项收“回还、转动”义，并以《孙子》“如转圆石于千仞之山者”为例。此处的读音选择与教材明确注音分开记录，不声称教材为“转”标过调。网络讲义对此有不同标注，课件与合成朗读应保持一致。

| 词句 | 课件采用的理解及处理 |
| --- | --- |
| 危乎高哉 | “危”在此指高，不用现代“危险”一义替代词义解释。整幅诗境仍可讨论其险。 |
| 四万八千岁 | 视为诗歌夸张，不将其转化为古蜀开国的精确年代。 |
| 蚕丛、鱼凫、壮士开山 | 保持“传说”标识，不当作可直接证明的历史事件。 |
| 扪参历井 | 参、井为星宿；结合夸张理解山高，不解释为真的摸到星体。 |
| 坐 | 主释“空、徒然”，并保留教材“一说坐下来”的另一解释。 |
| 凋朱颜 | 描写惊惧失色；不写成因旅途劳累而衰老这一单一解释。 |

## 4. 教学组织与参考解读

三次咏叹的教学线索取自诗句内部的变化：第一处接在开篇惊呼之后，第二处续以“使人听此凋朱颜”，末处续以“侧身西望长咨嗟”。课件将“惊叹—惊惧—忧叹”作为一种有文本根据的朗读方案，鼓励学生提出其他有依据的读法，不把语气变化设为唯一标准答案。

“山高路曲”“声景幽寂”“瀑流轰鸣”“关隘与守关者”等分析，属于依据诗句的教学归纳，不当作李白本人对创作意图的明确陈述。第五、六章将自然险阻与人事忧虑关联，同时保留劝归、山川感受、现实关切等多个层面。

六题均为开放思考，提供提示与可揭示的参考回答，不设置未经用户要求的选择题、自动判分或唯一答案。

## 5. 不纳入课件的争议信息

课件不写具体创作年份、不指定确切送别对象、不将作品确定解释为讽刺某一地方将领，也不将其说成安史之乱后劝唐玄宗回京之作。教材本身对创作背景使用“一般认为”措辞；本次课程的重点为文本与诵读，无需扩展这些问题。
