# V3.0 湿屏与习题修订验收

日期：2026-10-30。正式目录为 `山海行歌-V3.0`，预览端口 4180，资源版本 `3.0-water-study-r5`。

## 实现与观察

- 飞湍：保留场景中流动的瀑布与湍流，向近景推进时触发两次透视飞溅；短暂、不规则、柔边的水幕散开后，落在镜面的水珠挂留、拉长、汇流，沿原路径留有明暗折射水痕，再逐渐消退。逐次查看实际截图，去掉了第一稿过于规整的水膜外轮廓，修正了水痕偏白的问题。
- 滴头按重力加速并拉长，不让圆珠直接平移到底。流痕与滴头分别保存，因此水珠经过后痕迹仍然存在。暂停、拂去、退出渐退和再次进入触发均检查通过。
- 拼图：原先通用按钮的悬浮背景样式重置了图像裁切参数。本轮改用固定图片切片，交互只改变片块顺序；修复悬浮变化、交换后滚动跳位，提供完整原图参考。复原后六块边缘连续，隐藏编号。
- 题目：联网查阅五份教学和试题材料，扩充题量，采用字词解释、理解性默写、诗句赏析等常见题式。来源和改编对应见同目录《题目来源与改编对照.md》，亦随交付包附带。总分 100，客观题 60，表达题 40 为明确标识的学生自评，供教师复核。
- 原答卷按原键保留，新的题目使用独立草稿，迁移已读页面状态，提供导出旧答卷入口。
