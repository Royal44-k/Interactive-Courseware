# 山海行歌 V2.0 验收说明

本轮修改只发生在独立 V2.0 目录。V1.0 的 142 个源文件 SHA-256 均未改变；V1.0.zip 与原交付包完全一致。

## 请求落实

| 改进点 | V2.0 实现 |
|---|---|
| 首页云海 | 随机种子的三维分形噪声随风平移、形变；云层缓慢流动，不使用固定路径循环。暂停及减少动态设置生效。 |
| 全屏入口 | 顶栏恢复独立全屏按钮，手机布局也保留。 |
| 急促吟声 | 重制 118 段中文、英文入境与动作吟声；按短句加入停顿。“四顾／心茫然”中文 5.584 秒，英文 5.944 秒。旧研习、全文点播采用更缓语速。 |
| 鎏金波纹 | 仅在可行动时亮起；宴席暖金、冰雪青银、月林蓝玉、星河淡紫、海面金青等随景配色。 |
| 重复与抢述 | 入境短句设置情境；动作诗句在点击后随动作触发。音频结束事件控制接续，未读完不转场。 |
| 四顾天地 | 廊下、檐月、城河、庭阶四张独立画面；视线左、上、右、下移动，并在各方向留白。 |
| 高峰复用 | “噫吁嚱”采用陡壁狭隙仰视；“六龙回日”采用暖色神话高峰；俯察回川另有独立深谷。 |

| 一夫当关 | 正面远景、侧望城墙远景、木门近景三张新图；新手部叩门，三次轻叩后关门仍闭。 |
| 补齐意象 | 增补宴席案面、拔剑窗廊、锦城市井、竹溪归乡、西望古道、乘舟梦日、远海云帆。24 幕共 43 张场景图，跨幕无相同场景文件，图像哈希也全部不同。 |
| 自动吟游 | 首页一键开始，完整走过 24 幕并停于终章；支持暂停、面板阅读后接续、转手动、语言切换与后台暂停。 |

新增 18 张场景图和 1 张叩门手部图，另补录与新锦城画面一致的 2 段中英文研习解说。所有资源随交付包保存，原始生成图像保留在原路径。

## 验收证据

- 中文与英文分别跑通完整自动吟游：各 24 段入境、35 段动作音频均完整结束；最终停在第 24 幕，无残留弹窗、忙碌状态或未结束的吟声。流程检查采用测试侧加速，交付文件仍为正常速度。
- 正常速度复核停杯、拔剑、四顾、叩关关键帧，检查动作先后、可见范围与诗句时机。
- 暂停与恢复、动作中打开并关闭面板、英文拔剑转场、七类研习面板通过。
- 375×667、390×844、844×390、1280×720、1920×1080 的三种阅读语言组合通过，共 15 组。修正了窄屏英文顶栏换行及横屏封面文字与按钮重叠。
- 从实际 ZIP 解压，在浏览器断网模式下打开；176 个音频文件均成功读取时长，全部场景资源成功加载，控制台无错误。
- 最终包在 1440×900、连续调整窗口后的 8 秒首页采样：383 帧，95% 帧耗时不超过 25.1 毫秒，最大 26.3 毫秒，没有超过 34 毫秒的帧。此前独立首页采样 95% 为 16.9 毫秒。数据见 JSON 原始报告。
- ZIP 共 254 文件，CRC 校验与逐文件解压 SHA-256 一致。最终 ZIP 哈希见 package-report.json。

关键文件：checks/audit-report.json、checks/english-auto-report.json、checks/final-report.json、checks/delivery-report.json、package-report.json、scene-manifest.json、voice-durations.json、V1.0-sha256.json。

场景是诗意化教学图像，英文为教学译读。两首诗的原文出处、各自情绪结尾与教学衔接说明继续保留。杜鹃录音来源与许可见交付目录“素材署名.md”。
