# 蜀道难 · 第一人称诗境 · 逐镜修订版

2026-10-29 修订。本版按照参考视频的前景遮挡、器物动作、镜头移动和手动推进方式组织主体验。可直接离线打开 `index.html`，不依赖网络 CDN 或构建工具。

本轮重写了镜头衔接：背景、三维物件和人物前景共用 0.68 秒叠化；同一场景保留姿态，仅让文字短暂交接。手臂和灯具使用连续的抬起、收势与停留轨迹。图片、材质和转场通道在开始前准备，瀑布用 GPU 连续绘制水流，减少首次入景的长帧。暂停会同时冻结镜头、人物、水流和叠化。

## 交互

- 山门：前景双门旋转打开，镜头穿过门槛。
- 绝壁：从右侧搭入缺失的木板，栈道沿右侧悬崖弯曲。
- 青泥：三次点击对应三次迈步，第二步发生木板松动和坠落。
- 仰息：镜头抬升、手臂伸出，山景过渡到星空；随后收手和低头。
- 夜行：提起灯，局部暖光增强，枝头飞鸟振翅离开；放低灯后继续听山间回声。
- 飞湍：持续的水流扰动、飞溅粒子与雾气；靠近后保留动作终态。
- 剑阁：推门受阻，镜头和门板产生短促反馈，等待手动继续。

空格/右箭头推进，左箭头返回，P 暂停，M 静音，F 全屏。弹窗暂停主场景；跳章取消未完成动作。

## 内容与素材

完整原诗、字词解释、三叹研习、课后练习及文本来源在课件的学习工具中。第一人称引导语为教学创作，非李白自述。

背景与透明手部素材为生成艺术图；场景几何、动画、特效和五声音阶氛围音乐为本课件制作。中文音频由本地 Microsoft Huihui 语音合成，随课件保存。主题配乐与朗读均可单独关闭。

`vendor/three.js` 为 Three.js 0.180.0 的本地构建，许可证见 `vendor/THREE-LICENSE.txt`。

## 运行与验证

推荐桌面横屏，Edge 或 Chrome，并开启 WebGL。课件主体验已在 Edge 的离线 file 协议下，使用 1440×900 与 1280×720 两种尺寸检查完整流程、暂停恢复、弹窗、跳章和学习工具。不同设备性能会影响流畅度。

源文件位于本目录：`cinema.js` 控制动作、镜头及合成，`motion.css` 定义同步显示样式，`props.js` 提供实时场景物件，`story.js` 定义体验顺序，`app.js` 管理学习工具和控制流程。`assets/water-texture.js` 是瀑布图片的本地内嵌数据，使 file 协议下的实时水流也能离线运行。
