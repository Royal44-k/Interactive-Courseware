# 运行与数据

本课件是纯前端网页应用，使用 HTML、CSS、JavaScript、Canvas 和 Three.js。没有后端服务、学生账号或数据库。直接打开文件或用本地 HTTP 服务均可运行，离线包内资源完整。

- 运行资源在 `courseware/V3.0/assets`，第三方浏览器库在 `vendor`。
- V3.0 最新考核使用 `localStorage` 键 `shanhai-v3-learning-2` 保存研读状态、答卷草稿、提交结果；旧键 `shanhai-v3-learning-1` 保留并可导出旧答卷。
- 当前场景的运行状态由浏览器页面持有，不应把答卷保存功能理解为所有镜头播放状态均已持久化。
- 分数由本地脚本计算：客观题 60 分；表达题 40 分为学生量规自评，教师可通过导出的 JSON 复核。
- 更换浏览器、设备、站点来源或离线文件路径，清除浏览数据，可能导致无法沿用本地记录。仓库和 GitHub 本身不接收学生答卷。
- `npm start` 仅绑定 `127.0.0.1`，用于本机预览。仓库整理未自动启用 GitHub Pages，也未部署在线课堂服务。

如果后续需要局域网集中收卷或云端同步，需要另外设计身份认证、答卷存储、教师批阅及权限管理，不是把静态文件上传 GitHub 就会自动获得这些功能。
