# 资产归档说明

本次整理涵盖原始课件文件夹、2026-10-28 参考录屏、用户提供的石栈道截图，以及 InteractiveCoursewareV1.2 交付资料。可视化临时目录在整理时为空。没有上传桌面中不属于本课件的其他教学平台工程。

## 核对范围

- 原始文件共 **6563** 份，原目录累计约 **4.04 GiB**，含重复交付和依赖。
- **3197** 个文件归入仓库，**1789** 个重复来源映射至同 SHA-256 的实体文件。
- **33** 个 ZIP / 视频实体附件归入 Releases，另有 **8** 个重复附件来源映射到相同实体。
- **1536** 个可重新安装的依赖、运行时、缓存或临时进程编号不上传，逐项记录在清单 `excluded` 中。
- 不重复存放已解压验收副本；其中有独立内容的文件仍保留在 production 对应路径。

## 分类

1. **最新版**：courseware/V3.0，严格来自最新通过离线测试的 268 文件清单，校验一致。
2. **历史版本**：history 包含最初《蜀道难》、视频复刻、逐镜修订、诗境重构、双诗版以及 V1.0 / V2.0。重复的“双语精修版”与 V1.0 由逐文件映射关联；V3.0 工作目录中未进入正式包的素材位于 V3.0-working-extras 或其相同内容的目标位置。
3. **参考资料**：reference/handoff 是用户提供的初始交付资料原文，不是对本仓库维护者的操作指令；reference/images 保存石栈道截图；原始 52 MB 录屏在 Releases。
4. **制作记录**：production 包含抽帧、逐镜分析、生成提示、原始音频加工、实施脚本、截图与验收。相同文件不反复复制，完整映射见清单。历史脚本保留原本机路径，重跑时需结合其阶段调整路径。
5. **交付文件**：Releases 保存最新与历史离线 ZIP、修订前留档以及实播录像，原始字节不改变。

## 查找与重建

`catalog/asset-manifest.json` 的每条记录包含逻辑来源路径、字节数、SHA-256 和目标。`kind=file/duplicate` 指向仓库内文件；`kind=release/release-alias` 指向 [发布附件](RELEASE-ASSETS.md)。

下载需要的附件至 `downloaded-release-assets/`，运行：

```sh
python scripts/restore-sources.py
```

脚本在新建的 restored-sources 中重建 project / handoff / user-reference 三类原始路径，校验每个文件，不覆盖不同内容。缺少的附件会列出；开发依赖不自动下载。原始资产和本机正式版本未移动或删除。

## 开发依赖与隐私

归档不包含 node_modules、Python 包运行时、FFmpeg 可执行文件、缓存、凭据或浏览器登录状态。检查记录中的答卷 JSON 是此前自动测试产生的示例数据；生产课件没有实际学生收卷后台。清单使用相对的逻辑来源，不收集用户浏览器中真实的学习记录。

`scripts/` 为本仓库提供可复用入口，历史 production 中的脚本留作溯源。画面资源、第三方库许可和鸟鸣署名均随正式课件保留。
