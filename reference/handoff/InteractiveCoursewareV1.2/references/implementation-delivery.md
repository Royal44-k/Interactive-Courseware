# 第三阶段：实现、内部检查与交付

以已确认的功能、视觉及运行约定为输入。以下检查点全部由智能体自动执行，不逐个向用户索要通过许可；出现可修复的问题，修复受影响项后继续。只有超出已有授权的实质方案变更才需要用户决定。

## 选择能力与制作准备

先看能力池的简短索引，按本模块的教学机制、操作、视觉和运行条件选型。选中后读详细说明并执行[更新与版本固定](capability-pool.md)，无需使用第三方能力的模块可直接实现。

交给制作能力的材料包括：功能/状态编号、已确认视觉、实施约定、实际素材或制作计划、输入输出、依赖与验收条件。第三方默认布局、品牌、导航、工作流和交付格式不得覆盖定稿，不得追加无关账号或发布。

先确定公共状态与模块接口：进入、输入、状态变化、完成、暂停/恢复、重置、退出清理、尺寸变化。按需统一字幕、语音、计时及减少动态效果；不要求不需要这些功能的课件强行添加。

## 自动内部检查点

| 检查点 | 要做的事 | 通过依据 |
|---|---|---|
| C0 输入与运行条件 | 核对功能到视觉的覆盖、确认版本、资产身份和缺口；尝试目标打开方式与关键依赖 | 无未说明的关键视觉空白；缺口有可执行解决路径；已识别真正无法验证的限制 |
| C1 代表性界面与技术难点 | 用真实目标素材做最有代表性的单页和最高风险交互，可以是同一片段；完成进入、操作、反馈、退出 | 实际运行画面与定稿对照通过，关键机制可运行，单屏适配成立；不能以占位图、静态效果图或只成功调用库代替 |
| C2 逐模块实现 | 按覆盖表完成全部模块及关键状态；逐项实现并检查，而不是全部写完才第一次看画面 | 对应实际截图、状态反馈和完成结果；未批准的布局变化或明显视觉退化已修复 |
| C3 整体联调与学习体验 | 从入口走完整路径及重要分支、错误恢复；检查公共控制、模块连续性和提示 | 学习者知道下一步做什么；没有状态串扰、语音重叠、无意义等待或无出口；实际结果符合方案 |
| C4 最终打包与复验 | 生成ZIP、实际解压、按约定方式打开并完成关键操作 | 根目录、相对路径、资源及许可齐全；交付包与验收版本一致，限制如实记录 |

C1不通过时，先修复或更换等效技术路径再铺开依赖它的模块。可并行准备不受影响的部分。不能为了过检查删掉已确认功能，不能反复执行同一种失败尝试代替进展。

## 视觉还原与程序素材

每个关键界面保存运行截图，并关联对应视觉稿及状态；至少逐项查看构图、主体比例、素材身份、层级、文字密度、控件位置、反馈和导航。必要时并排或叠加比较，不用没有定义的“还原度百分比”代替检查。

未经授权的主视觉替换、额外侧栏/页脚、把场景动作移到脱离对象的按钮、重要内容挤压或遮挡，都应修复。响应式重排与字体渲染差异只能在定稿允许范围内调整；影响主要效果时记录并解决，不静默降级。

视觉图只代表效果。背景、设备、人物、手部、文字和动态对象按交互需要分别准备或程序绘制；画在图片中的按钮不能假装成已实现操作。明确每种素材是已取得、待生成、待程序实现还是占位，最终不能留未经说明的占位物。

对用户指定必须沿用的产品、标识或人物参考，保留身份一致性，记录裁切、透明、变形和重绘是否允许；未知结构用明确标注的功能示意，不能冒充真实结构。

## 可靠的交互与表达

- 用同一状态及计算模型驱动画面、数值、反馈与判定；不能以独立动画假装实验结果。检查动作前置条件、正常路径、错误恢复、重复输入、重试/重置及模块退出。
- 真3D须有实际几何或模型、材质、相机和可验证操作；等距SVG、图片投影与自由三维明确区分。检查部件关系、观察角度、遮挡、运动、复位和资源失败提示。
- 计算与渲染分离，约定单位、边界及误差。动画帧率不得改变科学结果或练习时长。
- 采用语音时，把画面、动作提示、语音/字幕和时序一起实现。检查首次播放所需用户操作、串行打断、暂停恢复、重听、静音、失败替代及退出清理；不能只把文字全部朗读而不说明下一步动作。
- 分别定义真实过程时间、讲解时间、练习时间和完成条件。教学压缩时长需在内容中说明；不要让体验因无限等待、长时间机械重复或隐藏条件无法完成。
- 多模块共用公共控制，暂停时哪些计时/动画/音频停止有一致规则。检查低输入量、连续点击、键盘和实际目标输入方式，不把“逻辑测试通过”扩大为真实触控通过。

## 分开验收功能、视觉和体验

| 维度 | 检查与证据 |
|---|---|
| 教学准确 | 定义、数据、单位、典型输入与结论一致，示意和适用条件明确，来源可定位 |
| 功能与状态 | 实际操作、预期结果、反馈、分支、错误恢复、公共控制均有检查；重要计算可用独立测试 |
| 视觉一致 | 每个独立模块及关键状态与确认稿对应，主要差异已修复或有授权依据 |
| 单屏适配 | 在约定窗口及必要的另一比例检查；文档/教学面板不需滚动，必要文字、热点和反馈均在视口内且可读。overflow:hidden或滚动尺寸为零本身不足以通过 |
| 学习体验 | 不依赖制作人员口头补充也知道操作对象、动作与下一步；反馈及时，等待合理，纠错后能继续，结束条件清楚 |
| 目标环境 | 按约定浏览器、输入方式及打开方式记录实际结果；确认资源、性能、网络依赖与控制台问题 |
| 最终包 | 实际解压并用解压后的入口验收，核对最后修改已进入ZIP，许可保留且路径不指向包外 |

记录检查方法、环境、预期、实际结果和证据位置。区分静态阅读、自动测试、模拟测试与真实浏览器。没有相应能力时标为未验证，不能以其他证据替代；约定离线必须实际断网检查，不把缓存当作离线保障。

## 打包与交付

课件独立文件夹，主入口为小写index.html。最终课件ZIP根目录直接包含该入口与必要资源，不再套文件夹；即使单个HTML也交付实际ZIP。包内本地资源采用相对路径，动态引用也要核对。

按约定双击或HTTP运行，提前处理file协议下模块导入、模型和数据加载限制；不能以开发服务器预览代替双击验收。保留使用到的许可证，制作过程、能力池、版本锁定记录与测试截图放包外。

交付简短使用说明、可获取的ZIP及影响使用的限制。没有生成ZIP或可用入口时如实说明未完成，不把代码块当成成品。使用了能力池的模块，按记录规则回填本次具体版本、效果、失败和限制。
